# Alder Lane: The Almost-Cleared Closing

An adversarial fictional Ontario residential file for The Underwriting Room. All people, creditors, instruments and contractual conditions are invented. It is not FCT guidance, legal advice or an expert-validated benchmark. The exercise tests reasoning over supplied evidence, not knowledge of legal deadlines or actual registries.

## Load it without contaminating the case

1. Extract `Upload-PDFs.zip`. Upload PDFs only, not this guide, the manifest or the answer key.
2. In the app, select an original case branch containing the seven starting documents and **none of the three prepared evidence reveals**. Create a new branch called `Complex Alder Lane`. This preserves your original demonstration.
3. Keep the signed closing date **2026-10-15**, purchase price **CAD 700,000** and new loan **CAD 500,000**. The unsigned October 22 extension is not an agreed fact.
4. In Documents, use **Add or replace PDF** to REPLACE each of the seven originals with its matching file below. Do not merely add these seven as duplicates. Replacing preserves the existing document category used by deterministic checks.

6. Confirm the active branch has **8 PDFs / 20 pages**. Do not reveal the original prepared authorization, updated payout or municipal clarification; those belong to the simpler scenario.
7. Run a full review. Save the brief before opening `ANSWER-KEY.md`.

If your branch already contains reveals, use a clean original branch or an isolated new browser session. Do not delete an existing session you want to keep.

## What makes this difficult

Evidence exists but may address the wrong parcel, wrong instrument, wrong work or only one condition. Several confirmations are genuine within the fictional record but narrower than the cover email claims. The reviewers must distinguish an amount from a release undertaking, a document-copy consent from joint execution, and a closed deck notice from an unresolved basement file.

The later evidence is deliberately insufficient for global clearance. A good output can remain unresolved. A confident answer without evidence should score poorly.

## Test sequence

- Full team: record missed issues, unsupported accusations, invalid citations and misplaced escalations.
- Single specialist: run mortgage, ownership and property separately. Preserve each run; do not mistake partial scope for a complete assessment.
- Human challenge: "The bank confirmed the letter is genuine. Why is the mortgage still open?" Attach the last page of the supplement.
- Human challenge: "The municipality says closed. Can you clear all municipal issues?" Attach municipal page 2.
- Human challenge: "I know Jordan personally. He can act alone." Supply no evidence. The gap should remain.
- Branch: change completion to October 22 as a hypothetical and rerun. The existing lender authorization still needs reconciliation, and the stated creditor dates must not be treated as valid indefinitely.

## Existing prototype limitations to watch

The board retains prepared Alder Lane labels; it is not an extraction-driven registry map. Source PDFs and findings govern this test. The model still uses demonstration rules and fixed primary issue codes. Closely related subissues may be grouped under a primary code; judge substantive coverage, not the number of cards.

The deterministic payout checker reads the original labelled Cedar validity date. It does not calculate the conditional update, second creditor amount, cross-security release or ledger reconciliation. A good review should flag these limits and request human verification, not invent calculations or silently call the conditional update unconditional.

Automatic cross-review is not guaranteed. Score whether material interactions are captured, not how many disagreements the agents manufacture. The expected answers are authored targets, not a substitute for review by an experienced Ontario underwriter or transaction lawyer.
